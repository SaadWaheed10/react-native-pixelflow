# PixelFlow examples

## Expo Snack (fastest)

1. Open [snack.expo.dev](https://snack.expo.dev)
2. Add dependencies: `react-native-pixelflow`, `react-native-safe-area-context`
3. Replace `App.tsx` with [`SnackApp.tsx`](./SnackApp.tsx)

## Local screen

[`ExampleScreen.tsx`](./ExampleScreen.tsx) is a drop-in screen for an existing Expo / RN app.
